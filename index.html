2. Bug Report #01

Judul[Bug] Pencarian menu gagal jika huruf besar/kecil berbeda
Severity / PriorityMedium / High
Reproduce1. Buka BakeFlow
2. Ketik “roti” (huruf kecil)
3. Klik Jalankan BUG
ExpectedRoti Tawar dan Roti Sobek Keju ditemukan.
ActualMuncul “Menu tidak ditemukan.”
Akar masalahTeks dibandingkan apa adanya, tanpa toLowerCase() dan trim().
EnvironmentChrome, Windows, BakeFlow v1.0.0
TipeCorrective maintenance

Kode JavaScript

Sebelum / Bug
function cari(nama, kata) {
  const n = nama;            // #01: tanpa toLowerCase()
  const k = kata;            // #01: tanpa trim() & toLowerCase()
  return n.startsWith(k);    // #04: startsWith, bukan includes
}
Sesudah / Fix
function cari(nama, kata) {
  const n = nama.toLowerCase();
  const k = kata.trim().toLowerCase();
  return n.includes(k);
}

3. Bug Report #02

Judul[Bug] Pencarian dengan kolom kosong tidak ditolak
Severity / PriorityLow / Medium
Reproduce1. Buka BakeFlow
2. Kosongkan kolom pencarian
3. Klik Jalankan BUG
ExpectedMuncul pesan “Masukkan kata kunci.”
ActualRoti Tawar ditampilkan seolah-olah cocok, padahal tidak ada kata kunci.
Akar masalahString kosong selalu cocok dengan startsWith(), dan tidak ada validasi input.
EnvironmentChrome, Windows, BakeFlow v1.0.0
TipeCorrective maintenance

Kode JavaScript

Sebelum / Bug
function cariMenu(kata) {
  // #02: tidak ada validasi input kosong
  const h = MENU.find(m => cari(m, kata)); // #03: find()
  return h ? [h] : [];                     // hanya 1 hasil
}
Sesudah / Fix
function cariMenu(kata) {
  if (!kata.trim()) return "Masukkan kata kunci.";
  return MENU.filter(m => cari(m, kata));
}

5. Bug Report #04

Severity / PriorityMedium / Medium

2. Ketik “Tawar” (T huruf besar)

TipeCorrective maintenance

Kode JavaScript (Pencocokan startsWith vs includes)

Sebelum / Bug
function cari(nama, kata) {
  // BUG #04: Hanya mencocokkan awalan kata dengan startsWith()
  return nama.startsWith(kata);

function cari(nama, kata) {
